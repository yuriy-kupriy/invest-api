# invest-api

Курсовий проєкт Node.js PRO 2.

**Домен** — Money Manager з детальним трекінгом інвестицій: рахунки (`cash` / `bank` / `brokerage` /
`property`) і транзакції (`income` / `expense` / `transfer` / `buy` / `sell`) в одній моделі.

Роботи по ДЗ ідуть окремими гілками `hw-NN` з PR у `main`.
